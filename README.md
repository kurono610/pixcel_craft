# Pixel Art Converter (ドット絵変換ツール)

画像および動画ファイルを、レトロゲーム風のドット絵（ピクセルアート）画像・動画に変換する Python ツールです。

最寄り補間（`INTER_NEAREST`）と K-Means クラスタリングによる減色処理を採用しており、ぼやけることなく「パキッ」としたレトロ感あふれるドット絵を出力できます。

---

## ✨ 主な機能

- **画像・動画の両方に対応**: `.png`, `.jpg`, `.mp4`, `.mov` などの主要形式をそのままドット絵化。
- **アルファ透過（PNG）の保持**: 透明背景付きの PNG 画像も崩さずに処理可能。
- **中間色の排除（減色処理）**: k-means クラスタリングにより、指定した色数（8色/16色/32色など）に減色し、レトロゲーム風の質感を再現。
- **GUI ダイアログでの簡単操作**: ファイル選択や解像度・色数の設定をポップアップ画面から直感的に実行可能。

---

## 📦 動作環境 / 依存ライブラリ

- Python 3.8 以上
- OpenCV (`opencv-python`)
- NumPy (`numpy`)
- Tkinter (Python 標準ライブラリ)
